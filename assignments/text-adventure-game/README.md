# 📘 Assignment: Text Adventure Game

## 🎯 Objective

Create a short text-based adventure game in Python where the player makes choices, explores different rooms, and tracks their inventory as they progress through a story.

## 📝 Tasks

### 🛠️ Build the Story Structure

#### Description
Design a text adventure with multiple choices and clear outcomes so the player can move through the story by typing commands or selecting options.

#### Requirements
Completed program should:

- Start with a clear introduction to the game and the player's goal
- Present the player with at least three different choices or locations
- Use functions to organize game logic and story sections
- Allow the player to move between rooms, locations, or scenes
- Display the current situation after each action so the game feels interactive

### 🛠️ Add Inventory and Game State

#### Description
Improve the game by tracking what the player has collected and deciding how choices affect the final outcome.

#### Requirements
Completed program should:

- Keep track of the player's inventory or collected items
- Update the inventory when the player picks up or uses an item
- Use conditionals to decide which choices are available based on current progress
- Include a win condition and a lose condition
- End the game with a clear message describing the outcome
- Make the story easy to understand and play through from start to finish
